# Python Image Analysis for Biological Microscopy

A learning and proof-of-work repository area documenting my practical Python training in biological image analysis at ETH Zürich (July 2026).

## Course scope

The course progresses from Python fundamentals to biological image-analysis pipelines and introductory machine learning:

- Python environments, syntax, terminal commands, loops, and functions
- NumPy for matrix manipulation
- pandas for tabular data
- matplotlib and seaborn for visualization
- Microscopy image formats including TIFF, LIF, ND2, OME-Zarr, and CZI
- OpenCV for image manipulation and introductory computer vision
- Building reproducible image-analysis pipelines from raw images to quantitative data
- Segmentation and tracking
- Morphological measurements and fluorescence-intensity quantification
- 2D/3D colocalization, spot counting, foci quantification, and nuclear-versus-cytoplasmic localization
- Introductory machine learning: training sets, classifier architecture, training, and validation
